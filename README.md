# Student Management System

## Project Description
A Java CLI-based Student Management System developed using Core Java, Object-Oriented Programming (OOP), ArrayList, and File Handling.

## Features
- Add Student
- View Students
- Update Student
- Delete Student
- Prevent Duplicate Student IDs
- Validate Invalid Numeric Inputs
- Save and Load Student Records

## Technologies Used
- Java 21
- IntelliJ IDEA
- ArrayList
- Object Serialization
- File Handling

## Project Structure
- Main.java
- Student.java
- StudentManagement.java
- FileHandler.java

## How to Run
1. Open the project in IntelliJ IDEA.
2. Make sure Java 21 is configured.
3. Open Main.java.
4. Run the main() method.
5. Follow the console menu.

## Storage
Student records are saved in students.dat using Java serialization.
